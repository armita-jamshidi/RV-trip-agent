- 2026-10-10: Campground booking (T26) is a handoff, not automation. Recreation.gov's RIDB API is read-only and there is no public reservation API; scripting the website would mean a bot on the traveler's account, which Recreation.gov's rules forbid as far as we know (the site is blocked from this environment, so this wasn't rechecked). Private parks use many different systems (Campspot, Newbook and others) with partner-only APIs. So after a person approves a stay, Dave gives a link to the exact site that fits (`/camping/campsites/{CampsiteID}`) with `startDate`/`endDate` parameters, the site name, dates and approved price, and for private parks their website and phone (Foursquare `tel`, a free field). The date parameters are unverified until recreation.gov is reachable; the dates are also written out in the steps. `dave.booking.book` stays the only path that could ever pay, if a partner API is added later. Campgrounds without a listed price get a note to ask, not a $0 proposal.
