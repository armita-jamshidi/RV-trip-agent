- 2026-10-16: Station fuel prices come from Google Places API (New) Nearby Search with `fuelOptions` (Armita's call, built into T35's PR): the first paid source, because no free source has station prices (decision 2026-10-09 on T22). It is optional (`GOOGLE_PLACES_API_KEY`), capped at 40 searches a plan, and its answers are never written to the on-disk cache because Google's terms don't allow storing prices (`CachedClient(..., cache=False)`), so tests use synthetic fixtures served by a mock transport. A posted price older than 14 days is ignored. Each state's average of the posted prices on the route replaces EIA's series for that state and fuel, and the route's average stands in for the U.S. one, so fuel costs work without an EIA key; fill-ups use a station's own price when it has one, else its area average.
