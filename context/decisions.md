# Decisions

- 2026-10-08: Python + Claude Agent SDK.
- 2026-10-08: Bookings need human approval per booking; no stored payment details.
- 2026-10-08: Free data sources first (see data-sources.md).
- 2026-10-08: LanceDB for vectors, behind an interface so pgvector can replace it.
- 2026-10-08: Fine-tuning via QLoRA on Google Colab (Kaggle as backup); start with Qwen2.5-3B, move to 7B only if needed. Claude is the baseline.
- 2026-10-08: One Notion task per branch and PR; hourly routine works one task per run.
- 2026-10-08: The agent runs with built-in Claude Code tools disabled (`tools=[]`); Dave can only call its own tools in `src/dave/tools/`, so it can't touch files or run shell commands.
- 2026-10-08: The request parser is one Claude call with structured outputs (`anthropic` SDK, `messages.parse`), not an agent loop. Claude returns only what the traveler stated (null otherwise), and code applies the domain defaults.
- 2026-10-08: The parser asks a follow-up only for origin, destination (unless it's a loop), nights and RV. A start date is optional; prices fall back to estimates without one.
- 2026-10-08: Parser accuracy compares free text loosely ("Moab, UT" = "Moab, Utah") and interest weights within ±0.3, since the weights are a judgment call.
- 2026-10-08: RV identification is an offline catalog match (9 manufacturers, their main model lines), not an LLM call. Model names that are everyday words ("View", "Classic", "Interstate") only match when the manufacturer is named.
- 2026-10-08: The catalog stores each manufacturer's site, not spec-page URL patterns. Manufacturer sites are blocked by this environment's network policy, so URL patterns can't be verified yet; T07 finds the spec page.
- 2026-10-08: Interests map to words in Foursquare category labels rather than category IDs, so the mapping survives taxonomy changes. Stop score = best matching interest weight × quality (60% rating, 40% popularity) × 0.5^(detour / 30 min). Unrated stops get a 6/10 prior.
- 2026-10-08: Routing uses the public OSRM demo server (car profile) with RV drive time = car time × 1.10, configurable. OSRM has no RV or truck profile; bridge heights are handled separately (T10).
- 2026-10-08: Driving days are split into equal parts (fewest days that keep each at or under 5 h), cutting the route geometry by distance. This avoids short last-day stubs. Campground choice (T17) may pull an overnight earlier, never later.
- 2026-10-08: Corridor search estimates detours from straight-line distance off the route (x1.3 road circuity, there and back, 35 mph) instead of routing every candidate; the planner routes only the few it picks. Default corridor is 15 mi each side.
- 2026-10-08: Campgrounds keep their RV sites (`Campground.sites`) because hookups and length only matter together: a campground with 50 A sites and 40 ft sites may have no 40 ft site with 50 A. Campground-level fields summarize the best site. Tent-only and non-RV sites are dropped at ingest.
- 2026-10-08: Foursquare campground search requests only free ("Pro") fields, so private RV parks come without rating, hookups or length. A paid field needs its own decision here. Duplicates across sources are merged by distance (≤0.5 mi with similar names, or ≤0.1 mi regardless), keeping the RIDB record.
- 2026-10-08: Campground embeddings use BAAI/bge-small-en-v1.5 through fastembed (ONNX on CPU, no torch, free and open). Search filters keep only campgrounds known to match hookups, length and distance; unknowns are left to T14's "call to confirm". No review text is embedded yet because no free source provides it.
- 2026-10-08: Scenic score = 0.5 meaning (closeness to five scenic descriptions, rescaled across the candidates) + 0.3 scenic word mentions (3 or more counts fully) + 0.2 rating (neutral 0.5 when unknown). Each score carries plain-language reasons. Nearby natural features are a planned fourth signal once Overpass/Foursquare are reachable.
- 2026-10-08: Pitstops come from Foursquare "Landmarks and Outdoors" and "Arts and Entertainment" (food is T20). Rating and popularity are paid Foursquare fields, so stops rank on interest fit and detour with neutral quality priors, and generic local places (plain "Park", "Playground", "Plaza"...) are skipped so they don't crowd out real sights. Up to 3 stops a day; detour driving counts against the 5 h limit. RVs over 25 ft get a parking warning, not a veto, for stops with 6+ other places within a quarter mile.
- 2026-10-08: "Largest X" stops come from a small curated seed list (`src/dave/largest_x.json`, each entry with its claim and the page it was checked against) plus Foursquare name searches for "largest" and "biggest" along the route, run only when the traveler's `largest_x` interest is above zero. Search results must say largest, biggest or tallest in their name; a searched place within 0.2 mi of a seed is the seed. Seeds start with the three checked attractions on the Austin to Nashville demo route.
- 2026-10-08: Booking approval binds to the exact terms: `approve()` stores a SHA-256 digest of what, dates, price, cancellation policy and link, and `book()` refuses (before calling any payment code) unless the proposal is approved and its terms still match. The model itself rejects approved or booked proposals without who, when and terms. The agent has no tool to approve, book or pay; approval comes from a person.
- 2026-10-08: Ticket rules (entrance fees, timed-entry windows) live in a checked list, `src/dave/tickets.json`, with each site's official page and check date, because they change yearly; stops not on the list get no ticket proposal. One entrance pass per park per trip; one America the Beautiful pass instead when separate passes cost more than $80 (U.S. residents). Arches needs no timed entry in 2026; its 2025 windows are kept so the rule stays testable. Ticket proposals are only proposals; buying goes through the approval gate.
- 2026-10-09: Campground embeddings (T30) are tuned with a contrastive loss (in-batch negatives plus one hard negative) on bge-small, the same model search already uses, so the tuned copy is a drop-in: exported to ONNX and loaded by fastembed from a local folder named in `DAVE_EMBED_MODEL`. A query counts as relevant when the campground's known facts (hookups, amps, length) or its own description back it up; there are no free review sources, so descriptions stand in for reviews. Scores are recall@5 and MRR of held-out phrasings over a stable held-out 20% of campgrounds. Results get their own line once Armita has run the notebook.
